# Changes

## 1.0.0 (2026-09-10)

First release.

- One-click connect to Asyntai from the plugin's settings page.
- The AI search bar in the top navigation bar, in place of the theme's own search box, or inside an element you choose.
- Reads only the courses you tick: descriptions, pages, book chapters, labels, activity descriptions and the names of attached files. Student data is never read.
- Shown to signed-in users only, unless you say otherwise.
- Status, allowance and a link to try your own bar, all on one page.
